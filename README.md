# Upsi Brand Assets                                                                                                
                                                                                                                     
  Official logos and brand assets for **Upsi**, the social disc golf app.                                            
                                         
  ## Download                            

  Logo package is available under [Releases](https://github.com/upsiapp/upsi-brand-assets/releases).                 
  
  Each release includes:                                                                                             
  - **Primary lockups** (with "Disc Golf App" descriptor) — on Upsi Pink, on black, on light background
  - **Secondary wordmark-only** — for known-Upsi contexts (doc headers, page footers, in-product chrome)             
                                                                                                                     
  Formats: PNG.                                                              
                                                                                                                     
  ## Brand guidelines                                                                                                
                                         
  Before using the logos, please review the Upsi brand guidelines. They cover which variant to use when, clear space,
   minimum sizes, co-branding rules, and misuse.                                                                                                                                                    
  ## Usage permissions                                                                                               
                          
  **Self-serve — no approval needed:**   
  - Using the "About Upsi" paragraph verbatim (see guidelines)
  - Linking to [upsiapp.com](https://www.upsiapp.com)                                                                
  - Writing about Upsi in press, reviews, or editorial coverage
                                                                                                                     
  **Everything else requires approval before publication** — co-branded lockups, modified artwork, new use cases,    
  anything that isn't in the self-serve list above.
